# IronCore Fitness

A responsive multi-page gym website built with Next.js App Router, TypeScript, and Tailwind CSS. The visual direction is inspired by the provided Fitness First screenshots: white top navigation, bold red brand block, full-width fitness hero photography, large editorial headings, and dark feature panels with red accents.

## Run locally
1. Install Node.js 20 or later.
2. From this folder run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Pages
Home, About, Programs, Features, Trainers, Membership, Pricing, Class Timetable, Contact, and Try Us.

## Notes
- Forms use client-side demo interactions and do not submit to a production backend.
- Replace sample plan prices, class times, contact information, and trainer profiles with verified gym details before launch.
- Photography loads from Unsplash URLs and requires an internet connection.
